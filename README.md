# Scoop bucket for transpareo

The [Scoop](https://scoop.sh) bucket for `transpareo`, the
command-line tool for the [Transpareo](https://transpareo.com)
platform. It lets you install and update the tool on Windows with
`scoop`.

## Install

```powershell
scoop bucket add transpareo https://github.com/transpareo/scoop-bucket
scoop install transpareo
```

## Update

```powershell
scoop update transpareo
```

## About the manifest

`bucket/transpareo.json` is generated by the release process of
[transpareo-cli](https://github.com/transpareo/transpareo-cli)
and pushed here on every release. It is never edited by hand, and
pull requests against it are not accepted. To report a problem
with the tool or with its installation, open an issue in the
[transpareo-cli](https://github.com/transpareo/transpareo-cli/issues)
repository.
